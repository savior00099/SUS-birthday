🎵 HOW TO ADD YOUR SPECIAL BIRTHDAY SONG:
=========================================

1. Place your MP3 file in this folder (d:\card\public\music\).
2. Name it:
   birthday-song.mp3

3. Or change the filename and song title in:
   d:\card\src\config\birthdayConfig.ts

Note: If no MP3 file is present, the website automatically plays a dreamy music-box synthesizer melody of "Happy Birthday to You" using the Web Audio API so it's always ready to play!
