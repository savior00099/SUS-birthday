📸 HOW TO ADD YOUR BEST FRIEND'S PHOTOS:
==========================================

1. Place your photo files in this folder (d:\card\public\images\).
2. By default, the website looks for:
   - photo1.jpg
   - photo2.jpg
   - photo3.jpg
   - photo4.jpg
   - photo5.jpg
   - photo6.jpg

3. You can also customize the filenames, add more pictures, or change captions in:
   d:\card\src\config\birthdayConfig.ts

Note: If a photo is not added yet, the website displays an adorable illustrated pastel fallback card automatically so there is never a broken image!
